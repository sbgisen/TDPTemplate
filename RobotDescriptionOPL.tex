	\item Mobile Base: differential drive
	      \begin{itemize}

	\item Torso unit: 1 DOF linear joint

		      \item PC: Intel NUC (NUC11PHKi7C)
	      \end{itemize}

\section*{SOAR Software Description}
% Please describe in this section the software you are using to control your robot. Consider the following example:

SOAR use the following open-source software components:

\begin{itemize}
	\item Platform: Ubuntu 24.04 ROS2 Jazzy
	\item Navigation: Nav2, MPPI controller
	\item Manipulation: MoveIt2, MoveIt Task Constructor
	\item Object Recognition: YOLOv8
	\item Behavior Architecture: SMACH
	\item Speech Recognition: Silero VAD, Whisper
	\item Speech Generation: GPT-4o-mini-tts
	\item LLM: GPT-4o
\end{itemize}
